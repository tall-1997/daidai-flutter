# v0.1.63 Pure Flat 状态栏修复

本版本修复 Pure Flat 风格主页面顶部状态栏区域的黑边，同时保持低 GPU、低合成开销的纯扁平渲染路径。

## 界面修复

- Pure Flat 背景层现在延伸至系统状态栏区域，消除顶部 Window 黑色底边。
- 业务内容继续位于 `SafeArea` 内，避免与时间、电量和网络状态图标重叠。
- Android 状态栏保持透明，并根据浅色或深色主题选择对应图标亮度。
- 关闭系统状态栏对比度遮罩，避免系统再次添加深色覆盖层。

## 性能约束

- 未增加半透明 AppBar。
- 未增加背景模糊、实时捕获或折射图层。
- Pure Flat 路径继续使用 Material 导航和轻量背景绘制。
- Liquid Glass 路径保持原有行为。

## 验证

- 增加 Pure Flat 状态栏背景层级和系统 UI 样式组件测试。
- 验证 Pure Flat 主壳层不包含 Liquid Glass 页面组件。
- GitHub Actions 执行 Flutter Analyze、测试、Android Release APK 和 iOS Release IPA 构建。

## 安装说明

- Android：下载 `Dumb-Panel-APP-v0.1.63-android.apk` 后安装。升级安装需使用与现有版本一致的签名。
- iOS：下载 `Dumb-Panel-APP-v0.1.63-unsigned.ipa`，通过自签工具安装。

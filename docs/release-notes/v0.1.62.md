# v0.1.62 性能与稳定性优化

本版本集中优化低端 Android 设备上的日志内存、网络轮询、图片解码、GPU 合成和 Root 子进程执行，同时保持 Pure Flat 默认视觉风格与可选 Liquid Glass。

## 日志与内存

- 执行日志、任务日志、订阅日志、脚本调试、依赖安装和 Android Runtime 日志统一使用有界缓冲。
- 日志同时限制最多 1,000 行和 200,000 个字符，超出后保留最新完整内容。
- 多行 SSE 事件会先拆分为独立行，再执行容量裁剪。
- 任务历史回放改用游标推进，避免大日志下反复删除列表首项。
- 增加多行裁剪、字符上限、Unicode 边界和回放游标测试。

## 网络与生命周期

- 修复日志分页、自动刷新和筛选请求之间的 generation 与 loading 状态竞争。
- 同一日志数据源保持单请求执行，刷新请求可在当前请求结束后继续处理。
- 日志列表、任务等待日志和脚本调试页面在 App 进入后台时暂停 Timer。
- App 恢复前台后按当前任务状态执行一次刷新并恢复必要轮询。
- 空闲任务日志轮询间隔调整为 5 秒，终态会完整停止降级轮询。

## 渲染性能

- Pure Flat 应用锁使用纯黑不透明遮罩，跳过全屏背景模糊。
- Liquid Glass 主框架减少为单个页面级捕获入口，降低重复纹理和合成层级。
- 背景图片按屏幕物理尺寸约束解码，减少超大原图带来的图片内存占用。
- 背景模糊改为静态图片滤镜处理，避免对整个动态页面执行 BackdropFilter。
- 应用路由统一使用无转场页面，减少缩放和位移动画开销。

## Android 平台

- Root 检测、文件读取、目录读取和命令执行移出平台主线程。
- stdout 与 stderr 使用独立线程并发读取，避免任一管道填满后阻塞子进程。
- Root 操作增加 30 秒超时、Android 23 兼容等待、进程终止和流资源清理。

## 安装说明

- Android：下载 `Dumb-Panel-APP-v0.1.62-android.apk` 后安装。升级安装需使用与现有版本一致的签名。
- iOS：下载 `Dumb-Panel-APP-v0.1.62-unsigned.ipa`。未签名 IPA 需要通过自签工具安装；仓库签名配置完整时 Release 会提供已签名 IPA。

## 构建说明

- GitHub Actions 使用 Flutter 3.41.5 构建 Android Release APK 和 iOS Release IPA。
- Release 工作流在 Android 与 iOS 构建成功后创建正式发行版并上传安装包。

# v1.0.1 环境变量卡片侧滑显示修复

本版本修复 Liquid Glass 主题下环境变量卡片透明导致侧滑操作按钮穿透显示的问题，并沿用 `v1.0.0` 的固定 Android 签名基线。

## 修复内容

- 环境变量卡片关闭时不再绘制启用、禁用和删除操作层，避免玻璃 Lens 折射卡片后的按钮。
- 拖动卡片时仅在右侧实际露出的区域绘制操作按钮，保持 Liquid Glass 背景效果。
- 卡片位移与操作层裁剪共用吸附动画，避免展开、收起和返回手势收起期间闪现。
- 保留环境变量卡片的左滑操作、点击收起、返回手势收起和 Pure Flat 渲染行为。

## 分发说明

- Android：`Dumb-Panel-APP-v1.0.1-android.apk` 沿用 `v1.0.0` 固定 JKS 证书，可从 `v1.0.0` 覆盖升级。
- iOS：`Dumb-Panel-APP-v1.0.1-unsigned.ipa` 需要使用有效 Apple 证书重新签名后安装。
- Android 自动更新清单继续保持关闭。

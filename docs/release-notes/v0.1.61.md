# v0.1.61 Pure Flat 默认视觉风格

本版本新增低 GPU 占用的 Pure Flat 纯扁平界面，并保留 Liquid Glass 作为可选视觉风格。视觉风格与浅色、深色、跟随系统模式可自由组合。

## Pure Flat

- 新安装和从旧版本升级时默认使用 Pure Flat。
- 主框架、底部导航、卡片、输入、开关、按钮、Chip 和弹层使用 Material 渲染路径。
- 内容表面使用不透明填充和单层边框，减少多层透明合成。
- 自定义背景图片保持原图显示，不应用背景模糊。
- 启动时先恢复视觉设置，避免首帧风格切换。

## Liquid Glass

- 可在“主题设置”中主动切换到 Liquid Glass。
- 保留现有玻璃背景、折射、模糊控件和底部导航效果。
- 已保存的背景图片和模糊强度在风格切换后继续保留。
- 修复 Slider 可空参数的编译兼容问题。

## 稳定性

- 修复视觉设置异步加载覆盖启动期间用户操作的竞态。
- 偏好读取异常时使用安全默认值继续启动。
- 增加视觉状态持久化、共享控件、主框架、页面背景和主题设置回归测试。

## 安装说明

- Android：下载 `Dumb-Panel-APP-v0.1.61-android.apk` 后安装。升级安装需使用与现有版本一致的签名。
- iOS：下载 IPA 文件。签名配置完整时产出已签名开发版 IPA；其余环境产出未签名 IPA，需通过自签工具安装。

## 构建说明

- GitHub Actions 使用 Flutter 3.41.5 构建 Android Release APK 和 iOS Release IPA。
- 发布流水线完成后可在本 Release 的 Assets 区域下载安装包。

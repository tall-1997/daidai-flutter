# v1.0.0 固定 Android 签名基线

本版本将经过上游能力对齐和可靠性加固的应用提升为 `1.0.0`，并建立固定 Android 发布证书基线。

## Android 签名

- Android APK 使用固定 JKS 证书签名。
- 发布流程验证 JKS 格式、RSA 4096 公钥、SHA384withRSA 证书签名算法和 2053-12-25 到期日。
- 发布流程验证 APK 签名证书 SHA-256 为 `A8:E6:CC:B8:2F:B9:77:44:34:06:93:57:2F:4F:FC:62:1F:64:00:62:60:B8:12:A0:36:8A:62:2F:F7:32:BF:0B`。
- 后续 Android 版本应沿用同一 JKS 证书，以支持从 `v1.0.0` 开始覆盖升级。

## 功能基线

- 保留完整 Multi-Cron 表达式、模板分组、面板时区和未知服务端值。
- 使用 Session Epoch 与 Panel Scope 隔离认证、Token 刷新、REST、SSE 和跨面板状态。
- SSE 支持续传、事件 ID 去重、退避重连和生命周期暂停。
- 增强端点按能力降级，列表和管理页面提供可恢复错误与重试入口。
- 全局任务观察器在任务进入完成、失败或终止状态时发送一次本地通知。
- 环境变量卡支持左滑启用、禁用、删除及返回手势收起。

## 分发说明

- Android：`Dumb-Panel-APP-v1.0.0-android.apk` 为固定证书签名安装包。
- 旧版本使用其他证书时，请先备份应用内数据并卸载旧版本，再安装 `v1.0.0`。
- iOS：`Dumb-Panel-APP-v1.0.0-unsigned.ipa` 需要使用有效 Apple 证书重新签名后安装。
- 本版本保持 Android 自动更新清单关闭，避免旧签名版本发起覆盖安装。

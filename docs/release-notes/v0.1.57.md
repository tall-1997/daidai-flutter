# v0.1.57 稳定性、日志能力与性能更新

本版本面向 `daidai-panel v3.0.0` 完成一轮兼容性、稳定性和性能升级，重点修复实时日志连接、分页一致性与页面生命周期问题，并补齐原始日志下载和会话客户端分类能力。

## 新增功能

- 新增原始执行日志下载，可通过面板签发的短时票据流式保存原始日志文件，保留控制序列和原始字节内容。
- 新增任务日志文件原始下载入口，自动生成安全文件名，并避免并发下载同名文件时互相覆盖。
- 会话管理增加客户端类型、客户端名称和类型图标展示，可区分网页端与 App 端连接。
- Android Runtime 安装日志支持标准 SSE 字段、多行数据和明确安装终态识别。

## 稳定性修复

- 修复实时日志收到业务终态后仍持续重连的问题，任务完成、安装完成、失败、未运行、关闭和超时状态均会正确结束连接。
- 修复 `done/reconnect` 在包含可选空格时被页面误判为业务终态的问题。
- 修复连续调用 SSE 连接时旧连接和重连计时器可能继续存活的问题。
- 修复登录日志、审计日志和 Open API 调用日志请求失败后跳过失败页的问题，页码现在仅在请求成功后提交。
- 修复订阅页面初始化期间退出页面可能触发异步生命周期异常的问题。
- 修复 Android Runtime 安装或卸载期间退出页面可能残留流订阅或触发页面更新的问题。
- 修复平台令牌首次加载失败后持续显示加载状态的问题，增加错误提示、重试入口和操作互斥保护。
- 修复任务分组候选仅扫描部分任务的问题，分组来源现在使用完整任务集合。
- 原始日志下载失败时自动清理残缺文件，并确保独立下载连接及时释放。

## 性能优化

- 任务实时日志、执行日志、依赖安装日志和订阅拉取日志改为约 32 毫秒批量提交，减少高频 `setState` 与滚动操作。
- 大日志改为逐行惰性构建和逐行 ANSI 解析，减少长日志全量文本重建。
- 已安装依赖列表改用 Sliver 惰性布局，降低长列表首帧和滚动期间的构建开销。
- 高频滚动卡片启用低成本 Liquid Glass 配置，在保留完整视觉层级的同时降低光栅化压力。
- 平台令牌列表改为按需构建，减少列表数据较多时的同步布局开销。

## 兼容性与清理

- SSE 解析兼容 `data:value`、`data: value`、CRLF、注释行和多行 `data`。
- 保持 Refresh Token 轮换、任务排队状态和异常断线自动恢复行为。
- 移除已停用 Android 本地面板的 `/api/local/*` 端点声明。
- 移除任务列表失效的空分页调用和公开头像请求中的空认证头。
- 辅助管理列表已按 `daidai-panel v3.0.0` 接口契约复核，直接列表接口继续完整加载。

## 安装说明

- Android：下载 `Dumb-Panel-APP-v0.1.57-android.apk` 后安装。升级安装需使用与现有版本一致的签名。
- iOS：下载 IPA 文件。签名 Secret 完整时产出已签名开发版 IPA；缺少签名配置时产出未签名 IPA，需通过自签工具安装。

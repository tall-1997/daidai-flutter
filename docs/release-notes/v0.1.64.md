# v0.1.64 跨版本能力降级与加载优化

本版本优化 App 启动、认证和核心页面首载流程，并增加按实际端点响应判断的面板能力档案。App 与面板可以独立升降级，旧面板继续提供基础功能，新面板增强入口按探测结果显示。

## 跨版本兼容

- 能力状态按规范化面板 URL 隔离，多个面板之间不会共享探测结果。
- 任务视图、面板设置、版本信息和多 Python runtime 使用实际端点响应判断能力。
- 404、405 和明确不支持响应形成 30 分钟负缓存，到期后自动允许重新探测。
- 超时、断网、连接失败和 5xx 归类为临时失败，保留功能入口和后续重试能力。
- 面板升级或降级后，能力缓存到期即可按新端点状态更新入口。

## 加载性能

- 仪表盘系统信息和任务统计并行加载，核心数据返回后立即显示。
- 面板标题与版本信息在后台并行补充，可选接口不会阻塞仪表盘。
- 任务列表先加载，任务视图独立探测；旧面板缺少任务视图时自动隐藏入口。
- 依赖列表、Python runtime 和分类计数并行加载，并跳过当前类型的重复计数请求。
- 登录与可信会话恢复流程移除仪表盘同步预加载，目标页面负责首次请求。

## 认证与多面板隔离

- HTTP 与 SSE 请求从进程内 Token 快照读取认证信息，减少逐请求安全存储访问。
- 登录、Token 刷新、退出和面板切换同步更新安全存储与内存快照。
- 多个并发 401 共享单次 Token 刷新，并发重放等待请求。
- 请求记录所属面板作用域，旧面板延迟响应不会清理新面板会话。
- 切换面板时统一失效仪表盘、任务、任务视图、依赖、日志、变量、脚本和用户状态。

## 安装说明

- Android：下载 `Dumb-Panel-APP-v0.1.64-android.apk` 后安装。升级安装需使用与现有版本一致的签名。
- iOS：下载 `Dumb-Panel-APP-v0.1.64-unsigned.ipa`，通过自签工具安装。

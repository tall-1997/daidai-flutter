# v0.1.59 HTTPS 登录稳定性修复

本版本修复 HTTPS 域名场景下点击登录后长时间无响应的问题，并增强连接诊断和首次面板登录流程。

## 登录修复

- 登录、初始化和验证码配置等公开认证接口不再携带本地旧 Token。
- 公开登录接口返回 401 时直接显示登录错误，不再进入 Token 刷新和请求排队流程。
- 登录和验证码配置请求增加明确超时，避免反向代理异常时持续等待。
- 每次登录前清理历史错误，确保当前 HTTPS、验证码或账号错误能够准确显示。

## HTTPS 连接诊断

- 服务器健康检查会验证 Daidai Panel 的标准健康响应，避免将重定向页面或普通网页识别为面板。
- 明确区分 HTTPS 证书、TLS 握手、DNS 解析、连接超时和 HTTP 状态异常。
- 登录页面实时显示服务器检查、初始化检查、验证码检查和登录阶段。

## 首次连接

- 首次录入服务器后重新读取面板初始化状态。
- 初始化状态检查失败时停止登录并显示连接错误，避免误走普通账号登录流程。

## 安装说明

- Android：下载 `daidai-flutter-v0.1.59-android.apk` 后安装。
- iOS：下载 `daidai-flutter-v0.1.59-ios.ipa`，根据设备签名环境安装。

## 验证说明

- 增加公开认证路径和旧 Token 登录 401 回归测试。
- 增加服务器地址格式和 HTTPS 健康检查基础测试。

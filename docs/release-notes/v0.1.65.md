# v0.1.65 上游能力对齐与发布链加固

本版本完成 Dumb-Panel-APP 正式版本能力对齐后的可靠性收口，重点加强 Multi-Cron 数据完整性、会话隔离、SSE 续传、跨面板状态、错误恢复、增强端点降级、本地通知和正式发布资产验证。

## 任务与配置完整性

- Multi-Cron 编辑完整保留表达式顺序和重复项，同时提交完整列表与首条兼容字段。
- Cron 模板支持分组和字段别名，并展示面板执行时区上下文。
- 未知任务类型、Python Runtime、通知渠道、用户角色、订阅类型和系统配置值保持原始值。
- 系统配置显式空字符串与字段缺失分开处理，避免保存时覆盖服务端语义。

## 会话与跨面板隔离

- 登录、退出、认证失效和面板切换推进 Session Epoch。
- REST、Token 刷新、SSE 和页面异步回写校验 Session Epoch 与 Panel Scope。
- Dashboard、任务、日志、通知、订阅、用户、脚本、环境变量、依赖和系统设置状态按面板隔离。
- 旧会话的延迟请求转换为取消结果，避免污染新登录或新面板状态。

## SSE 与任务通知

- SSE 支持跨数据块解析、CRLF、多行 data、事件 ID、空 ID 和服务端 retry 指令。
- 重连携带 Last-Event-ID，并使用最大 30 秒的有界指数退避。
- 显式事件 ID 使用有界缓存去重，保留合法的重复日志文本。
- 全局任务观察器独立于实时日志页面跟踪运行终态，完成、失败或终止时发送一次本地通知。

## 兼容与错误恢复

- 增强管理端点按面板记录 supported、unsupported 和 temporary failure 状态。
- 旧面板缺少健康诊断、平台令牌、配置脚本、Android Runtime 或依赖清单时自动降级。
- 服务器连接支持 HTTPS 与 HTTP 单次互试，公网 HTTP 继续要求明确安全确认。
- 任务、备份和 Open API 等页面保留已有数据，并显示非阻断错误与重试入口。
- 原始日志支持过期票据续期、临时分享、原子保存和临时文件清理。

## 交互与平台能力

- 环境变量卡增加左滑启用、禁用和删除动作，系统返回手势优先收起动作区。
- 健康诊断路由纳入管理员权限控制，面板重启操作展示成功或失败结果。
- iOS 更新弹窗可打开可信 GitHub Release 页面。
- 增加 Face ID 用途说明并补齐 Android、iOS 原生外链通道。

## 发布完整性

- 普通 CI 负责 Flutter Analyze、Flutter Test、Android APK 和 iOS 无签名构建验证。
- 正式标签发布要求 Android keystore、固定证书 SHA-256、iOS 证书和 Provisioning Profile。
- Android APK 校验包名、版本、签名和差分重建结果，并生成完整更新清单。
- iOS IPA 校验 Bundle ID、版本、build number、Team ID、Provisioning Profile 和 entitlements。

## 安装说明

- Android：下载 `Dumb-Panel-APP-v0.1.65-android.apk` 后安装，升级安装要求签名证书与已安装版本一致。
- iOS：下载 `Dumb-Panel-APP-v0.1.65.ipa`，根据 Release 使用的签名分发方式安装。

# v0.1.58 上游契约兼容与数据安全更新

本版本完成 daidai-panel v3.0.1 上游契约审计修复，重点恢复任务和环境变量导入，补齐任务终止、通知渠道、订阅鉴权和动态系统配置能力，并加强凭据保护与错误恢复。

## 导入与备份

- 任务导入改用 JSON 协议，兼容直接数组及常见导出包装，并限制文件大小。
- 环境变量导入支持合并与替换模式，增加 1 MiB 限制、变量名和重复记录预检以及替换确认。
- 手动备份完整支持任务视图配置。

## 任务与日志

- 任务支持成功退出码和终止时通知配置。
- 任务运行结果与日志状态完整支持“已终止”，并为未知状态和未知任务类型保留原始值。
- 日志支持终止筛选、明确错误重试和小时级耗时格式。
- 仪表盘增加今日终止统计。

## 通知与订阅

- 通知渠道使用服务端动态字段 schema，并在辅助接口失败时继续显示已有渠道。
- 通知配置值统一使用字符串协议，SMTP SSL 支持自动、开启、关闭三态及历史别名。
- 编辑通知渠道时保留未知配置和已有凭据；跨渠道类型切换会隔离旧配置。
- 订阅支持无鉴权、SSH 和 HTTP Token 鉴权，兼容旧版 SSH 数据。
- 密码、Token、Secret 和 Key 默认隐藏，编辑时空凭据保留服务端原值。

## 稳定性与兼容性

- 系统设置根据 `/api/configs` 动态生成控件，仅提交变化字段，并在失败后重新加载服务端状态。
- 任务、日志和系统设置加载失败时显示错误及重试入口。
- Access Token 刷新采用单次重放标记和并发 single-flight，重放再次返回 401 时安全结束会话。
- 未知依赖状态保留服务端原始值，避免误报为已安装。

## 安装说明

- Android：下载 `Dumb-Panel-APP-v0.1.58-android.apk` 后安装。升级安装需使用与现有版本一致的签名。
- iOS：下载 IPA 文件。签名 Secret 完整时产出已签名开发版 IPA；缺少签名配置时产出未签名 IPA，需通过自签工具安装。

- 本版本增加导入解析、通知配置、订阅鉴权、任务日志契约和动态系统配置回归测试。
